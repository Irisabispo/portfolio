Meu portfólio pessoal desenvolvido para apresentar minha trajetória como estudante de Análise e Desenvolvimento de Sistemas, meus projetos e minha evolução na área de desenvolvimento web.

## ✨ Sobre o projeto

Este portfólio foi desenvolvido com foco em uma interface moderna, responsiva e alinhada à minha identidade visual.

A estrutura foi construída utilizando HTML semântico, enquanto os estilos são organizados em SCSS e compilados para CSS.

O projeto segue uma abordagem mobile-first, utilizando media queries para adaptar a interface a diferentes tamanhos de tela.

Além de apresentar meus projetos e habilidades, o portfólio também foi pensado para demonstrar minha evolução prática durante os estudos.

## 🚀 Funcionalidades

- Layout responsivo e adaptável a diferentes dispositivos
- Abordagem mobile-first
- Menu de navegação para dispositivos móveis
- Seção de apresentação pessoal
- Marquee horizontal com tecnologias e ferramentas
- Cards de habilidades com interações visuais
- Seção de projetos com pré-visualizações
- Links para projetos e redes profissionais
- Seção de contato com e-mail e WhatsApp
- Animações e microinterações
- Suporte à preferência `prefers-reduced-motion`
- Organização dos estilos utilizando SCSS
- Compilação de SCSS para CSS
- Publicação do projeto utilizando Vercel
